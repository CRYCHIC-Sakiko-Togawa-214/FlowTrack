THE METHODCAUSAL EXECUTION

Keep the edit.
Track the motion.

FlowTrack treats editing as an execution problem. It carries a stable edit direction across solver steps, uses response strength to decide where the signal is trusted, and preserves the source trajectory everywhere else.

01 / OBSERVE

Read the edit signal

Measure the target–source velocity difference online as the edited rollout evolves.

rk = vtarget − vsource
02 / CARRY

Carry a stable direction

Blend the current evidence with the direction already supported by previous steps.

mk ← rk + λmk−1
03 / EXECUTE

Spend the signal where it matters

Support-aware execution limits weakly supported changes and protects unedited regions.

uk = sk ⊙ mk
